# DevPulse Workspace

DevPulse Workspace is a high-performance, modern project management and team collaboration web application built with React, Tailwind CSS, and Vite. It features an interactive Kanban board, real-time data persistence, state-of-the-art UI/UX, and comprehensive project analytics.

---

## Features

- Interactive Kanban Board: Smooth drag-and-drop workflow powered by @hello-pangea/dnd.
- Global & Local Search: Instant filtering by keywords, priorities (Urgent, High, Medium, Low), and projects.
- Full CRUD Operations: Create, view, update status, and safely delete tasks & projects with double-confirmation modals.
- Persistent Data: Local storage integration ensures zero data loss on refresh.
- Toast Notification System: Instant feedback on user actions.
- Modern Dark Theme UI: Modular UI system built with reusable cards, badges, buttons, drawers, and inputs.

---

## Tech Stack

- Frontend: React.js, Vite
- Styling: Tailwind CSS
- Icons: Lucide React
- Drag & Drop: @hello-pangea/dnd
- State Management: React Context API (WorkspaceContext)
